# First-session usability update

The novice route is now: open one free pack → reveal the five saved characters → acknowledge the opening and continue to Battle → use the suggested three-character squad or change it → start Comment Section → learn Attack, Guard and Special inside the fight.

The Home screen recommends one next action, derived from actual save state. A pending pack is resumed; an unfinished battle or Roast Night is resumed; an empty first-pack wallet points to free rewards. There is no new reward, entitlement, save schema or forced redirect. Recommended squads use only owned regular/foil characters and free starter loaners, with a preference for three factions. Recommendations never spend or mutate inventory. The guided start uses campaign mode explicitly, regardless of any previously selected lobby mode.

The primary navigation is Packs, Battle, Collection and City. Market, cosmetic props, Jobs, Roast Night, Rankings, Lore, cinema tools and settings remain available under More. Novice Home hides promotions; novice Packs hide preview characters, sidebars and idle effects. Reveal-all is the main reveal action. The pack and first-battle action buttons appear before long secondary content. Advanced squad options stay in the full lobby; novice casting offers a short optional disclosure.

The old welcome and first-battle rules dialogs no longer open automatically. Manual help remains available. Inline battle text explains when it is the player's turn, what each action does and why the special requires hype. Existing cinematics and the punk artwork remain. After a completed fight, the original fuller game UI returns; rewards are still awarded by the same authoritative commands.

The guide can be dismissed at any point and restored for a new-player account through More. That display preference is local to the device; gameplay progress and the derived step continue through the existing save. Established players are not forced through the guide. More offers manual How to Play once a battle has been played.

Validation: TypeScript, production build and272tests, including the entire committed first-pack → revealed → acknowledged → recommended-squad → saved first-battle transition. Read-only derivation, foil ownership, duplicate pulls, loss recovery, missing packs and unfinished encounters are covered. Browser DOM/playback and real novice usability observation remain unverified because the supported browser-control skill is unavailable. These checks confirm program behavior; they do not prove the usability problem is fully resolved.
