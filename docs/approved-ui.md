# Rejected atlas experiment — historical record

Version 37 used rectangular crops of the approved mockup as runtime scenes. The user rejected that approach because a flat screenshot with click regions does not create a living game city. That version was saved but never deployed. Its runtime components, stylesheet, atlas copy and review script have been removed.

The original supplied images remain unchanged in `docs/design-references/approved-expanded/`. They are design references, not runtime scenery. `expanded-v2.png` remains the composition and art-direction reference.

The replacement city block uses independently rendered buildings, actors, traffic and ground, with actual DOM controls and saved game commands. See `docs/living-city-block.md` for the delivered scope and verification limits. This checkpoint does not certify an exact reproduction of all four mockup screens.
