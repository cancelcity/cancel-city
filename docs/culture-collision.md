# Culture Collision

This update expands the existing punk game from 42 to 50 residents. It preserves current layouts, original card IDs, tier odds, old reward milestones, cloud save schema2, existing inventory and paused battle crews.

The new set contains Mew Khalifa (original fictional adult cosplay character; name is a public-figure/cosplay pun), Clip Farmer, Live Laugh Lawsuit, Sigma Landlord, Auntie Fact Check, Algorithm Daddy, Touch Grass Final Boss and Verified Goblin. Jokes target internet behaviour, celebrity culture and monetization. All quotes/posts are scripted fiction. The new eight have 48 distinct alpha acting sprites; the original five full acting casts remain and Apology Influencer gains six new poses, for14 casts/84 frames. Other existing residents retain their prior transparent action art.

Each new resident has a unique combat kit, special direction, portrait, meme profile and poster. Set-three completion awards three packs once. Existing set completion rewards remain independent.

## Battles

Six paired finishers cost 3 active hype plus1 standing partner hype and can be used once per side per fight. One committed deterministic event records both participants; the renderer presents its existing result without granting rewards. Pair guide and free duo previews are in Battle. Rules3 enables duos; rules1/2 remain supported. Roster1 daily crews use original30; roster2 uses original42; roster3 uses all50. Matching opposing character IDs no longer cause damaging mirror specials to be presented as support.

## City

Each of six building kinds has a finite incident. An assigned resident is required. Choose one pack or20 Influence; save an ending and reward marker together. Replays show the saved ending without commands or extra grants. Both directions of marker/state agreement are validated. Old cities default to empty incident records.

## Presentation

Pack tearing uses the shared deterministic Canvas painter: wrapper foil/creases, cap separation, debris and sealed-card fan. Epic/Mythic spotlight scenes use only actual newly revealed committed pulls. Skip, hidden-tab pause and reduced motion remain available. Ordinary packs retain published60/25/10/4/1% rarity weights. Pull presentation never rolls or grants again.

Mastery3/10 scored wins unlock local-menace/gold headline frames and a victory poster (full acting sequence where that cast exists), alongside existing pack milestones. Foils/mastery are cosmetic. Scripted callbacks vary with duplicate quantities and mastery milestones. No automatic JSON downloads added.
