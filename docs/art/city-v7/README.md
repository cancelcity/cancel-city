# City districts — production pass v7

Created with the built-in ImageGen tool using the owner's approved Overtime and Rug Street/404 mockups as references. Six separate full-screen scenes replace three crops of the overview and a shared finance/technology scene. All 41 existing addresses and their saved story IDs are retained. Existing card portraits supply character identity in selected-building cards; environmental pedestrians are incidental.

The native outputs are 1672 × 941 (Cloutside: 1672 × 940), encoded to WebP quality 92 without resizing. These are not 4K masters. The practical quality improvement is independent district composition, larger buildings, native HTML labels and a source-aware zoom cap. At very large desktop resolutions, base fit can still exceed the source resolution. True high-DPI/fullscreen close-ups remain a future higher-resolution art production task.

Raw PNG masters remain in this canonical Site repository; all runtime WebPs are included in the downloadable source mirror. Previous runtime assets are preserved.
