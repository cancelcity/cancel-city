# Cancel City illustrated atlas

The owner approved the expanded city, Overtime Downtown, and Rug Street / 404 Quarter mockups. These production backgrounds preserve those layouts, buildings, character sculptures and inked comic finish. Their painted navigation, account counters, selected-building cards and zoom buttons were removed with the built-in ImageGen tool. All player controls and balances in the shipped city are live HTML.

## Runtime assets

- `public/assets/city-v6/city-overview.webp` — six connected public districts and the illustrative player-block landmark.
- `public/assets/city-v6/overtime-downtown.webp` — the depot, construction yard, offices, courthouse and fire station.
- `public/assets/city-v6/rug-street-404.webp` — finance and surveillance districts around the canal.

Original PNG production masters in this directory remain in the Site source repository. The playable GitHub mirror includes every runtime WebP; its omitted-authoring-assets manifest lists the optional PNG masters.

The overview's player-block architecture is an illustrated landmark, not a representation of a player's owned properties. Its selection card reads the real save. Manage Block opens all twelve actual saved plots, residents, levels, jobs and construction actions. Public addresses reuse existing story records or open named game services; the atlas does not introduce a second reward system or pretend that treasury, delivery or hotel minigames exist.

## Exact production edit prompt

The following built-in ImageGen prompt was applied separately to each approved mockup as its sole edit target:

> Edit this exact approved Cancel City city artwork into production game BACKGROUND SCENERY. Preserve the exact image composition, fixed isometric camera, every building location and silhouette, all character identity sculptures, roads, canals, skyline, incidental architecture signs, ink linework, colors, details, illumination and sharp premium satirical comic art. This is surgical cleanup, NOT a redesign. REMOVE ONLY THE OVERLAID USER INTERFACE: the entire black navigation strip across the top (CANCEL CITY logo, HOME/CITY/COLLECTION/PACKS/BATTLE/MARKET labels, currencies and avatar), the black rectangular selected-building card in the lower left corner (including its thumbnail/text/pinkbutton), and the small stacked plus/minus zoom buttons lower right. Inpaint those removed UI areas with natural seamless continuation of the same city scenery and skyline/street/foreground that would be underneath. Do NOT add any UI, border, labels or floating controls. Keep existing diegetic district and building signs as they are. Preserve all scene geometry and spatial relationships pixel-faithfully. Whole canvas is world illustration, no navigation/header panels. Output a single clean high resolution 16:9 artwork as close as possible to reference, ideal 2048x1152. The exact rest of this approved art is required.

Generated PNG dimensions are 1672 × 941. Runtime WebP encoding uses quality 92, preserving the complete canvas without cropping or creative alterations. Existing evidence-removal van and courier sprites supply subtle ambient routines. Motion respects the pause control, reduced-motion preference and hidden tabs.
