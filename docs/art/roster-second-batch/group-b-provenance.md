# Second roster batch — art group B

Production used the built-in image generation tool. The original deck portraits CC001, CC014 and CC026 were visually inspected; CC001 and CC014 were supplied as palette, composition and scratched-ink style references. Every final portrait has a separate matching six-pose transparent whole-character sheet. No separate body-part rigs are used.

Characters: CC009 Olaf Global Warming, CC010 Homelesslander, CC011 Nine-to-Five Nanami, CC017 MrLeast.

Runtime portraits: `public/assets/roster-b2/CCxxx.webp` (896 square) and `CCxxx-small.webp` (384 square). Runtime acting sprites: `public/assets/actors/CCxxx-b2-0.webp` through `CCxxx-b2-5.webp` (neutral, anticipation, release, recoil, victory, failure). Per-character originals, exact portrait and pose prompts, final actor dimensions, contact-point anchors and visual proof sheets are stored under each character directory beside this note.

Sprites preserve generated alpha. Sharp performs only mechanical cell extraction, transparent-bounds cropping and WebP encoding. Anchors use observed foot contact points; one standing base height remains shared across all six poses, so seated and crouched characters remain shorter. All final poses were visually inspected for connected complete bodies and uncut held props. Visual proof sheets use a flat paper-colored background to check transparency and legibility; they are review artifacts, not runtime artwork.

The initially proposed Darth Hater image was rejected by the image tool twice, including a nonviolent customer-review prompt. No further Darth generation was attempted. The parent chose the materially different MrLeast identity from the user's supplied roster list. MrLeast is fictional exaggerated creator satire, with no factual misconduct allegation, brand logo or voice imitation.
