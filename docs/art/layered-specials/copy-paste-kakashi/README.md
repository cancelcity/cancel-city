# Copy-Paste Kakashi layered cinematic assets

Two eight-pose transparent sheets and one fixed office-dojo plate were generated with the built-in image tool and inspected against the current CC013 card and established full-body actors. Silver spiky hair, tilted headband, navy mask, olive flak vest, navy outfit, white straps/wraps and open-toe sandals stay consistent. The large ivory cylindrical shoulder scroll is retained from the existing cast.

Both sheets are 2 columns × 4 rows, ordered row-major. Each contains exactly eight large connected alpha components at threshold48. Extract by component membership, not equal cells, because hair and toes can cross nominal row boundaries without touching a neighbor. Tiny detached surprise ticks can be dropped. Real alpha is present; RGB under zero-alpha background is harmless matting and subject alpha is usually253.

These are actor-only figures. The leaning and button-press poses extend a hand to an implied waist-high photocopier so the renderer can composite and animate the machine separately. No clone, moving paper ribbon, copyright mark or energy effect is baked in. Ending paper props are held by connected hands. The instruction sheet has simple triangle marks and does not clearly read as upside-down; a separately overlaid reversed mark can make that gag explicit.

The background is one empty fixed tatami office with distant filing furniture and a back-right copier. It has a broad clear foreground and no character, moving paper or text. All exact prompts and component boxes are retained here. No app or publication code was edited.
