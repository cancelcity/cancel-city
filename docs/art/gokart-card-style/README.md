# Gokart: original card-art correction

The user rejected the first film's polished anime look as inconsistent with CANCEL CITY's cards. This revision redraws every consumed frame and the poster using the actual CC026 and CC010 portraits as style references. It keeps scratchy black hatching, stipple/newsprint grain, rough contour, exaggerated eyes/mouth/brow, loud flat acid-yellow and magenta ink, and the game's black city/palm silhouettes. It preserves the six-shot edit and original sound design.

All art is generated with the built-in imagegen tool, using explicit style-transfer edits of the original shot sheets. This is a complete raster redraw, not a color filter. Exact prompts, new original sheets and crop metadata are retained here per shot. The previous art remains in ../gokart/ for traceability; runtime film metadata selects only these corrected drawings.

Versioned output: public/assets/gokart/card-style-v2/full-throttle.mp4, poster.webp and six thumbnails. Runtime source manifest: src/data/gokart-film.json. The preview page also returns to the established paper/ink, magenta/acid controls and city backdrop.

The limited drawing cadence and source-resolution limits remain. This correction addresses art direction; it does not claim to add studio animation in-betweens. Browser, phone and audible playback remain unverified without the managed browser capability. File decode, media streams, coverage, TypeScript and build checks are performed before publication.
