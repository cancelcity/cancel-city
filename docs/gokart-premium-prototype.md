# Gokart — Full Throttle

Current playback uses the layered rebuild: fixed scenery plates, intact transparent character/kart sprites, continuous whole-actor movement and separately animated effects. It runs for 5.8 seconds at 60fps. See `docs/art/gokart-layered/README.md` and `scripts/render-gokart-layered.mjs`. The previous 9.6-second card-style version described below is retained as source history, not selected by current runtime metadata. The original full-frame interpolation experiments were rejected for visible contour/background distortion.

Standalone six-shot cinematic prototype at `/cinema/gokart/`, selected after the user asked for a substantial animation-quality improvement inspired by Dokkan specials. The first film's clean anime art direction was rejected as unlike the game's cards. The current version redraws every consumed frame in the original dense scratchy ink, neon acid-yellow/magenta, exaggerated caricature style, using actual CC026 and CC010 portraits as references. No existing combat special, card ID, pull pool, save schema, inventory or battle reward behavior is changed.

The 9.6-second film uses 51 unique reference-guided drawings: eight ignition close-ups, eight launch/reveal drawings, eleven drifting drawings, eight frontal rush drawings, eight collision drawings, and eight comedic ending drawings. One unexpected rear-angle drift drawing is deliberately excluded. Current original sheets, exact generation prompts, mechanical crop provenance and the hero reference are preserved in `docs/art/gokart-card-style/`; the prior version remains in `docs/art/gokart/`. Built-in imagegen produced every raster illustration; no external animation or sound recording was copied. The correction prompt set is retained with the corrected originals in each shot folder.

The artwork is assembled with timed cuts, a modest camera push, restrained collision shake and an original synthesized stereo Foley/tonal bed. The ending has a quiet beat followed by the wheel rolling away. There are no separated-body-part rigs. The final H.264/yuv420p, AAC 48kHz MP4 has fast-start metadata and captions. The rendered video and poster are at `public/assets/gokart/card-style-v2/full-throttle.mp4` and `public/assets/gokart/card-style-v2/poster.webp`. Rebuild with `node scripts/render-gokart.mjs` using FFmpeg, Sharp and @napi-rs/canvas from the artifact runtime.

The player supports replay, pause, seeking, half speed, mute, fullscreen, background pause, error feedback, native video controls and scene descriptions. System/game reduced motion selects a still-frame chapter viewer; the user may explicitly enable animation. Existing music stops during playback and resumes according to its setting when playback ends or pauses. Previews spend no game resources.

Quality limits: this is a prototype, not a claim of matching finished studio animation. Native sheet cells are encoded at 1280×720; encoding does not add source detail (exact cell sizes are in the crop metadata). Drawing cadence is deliberately limited, with longer holds for the gag and a faster frontal rush. The sheets retain some composition/proportion drift and missing in-betweens. The art-direction correction preserves these motion limits. Further improvement requires higher-resolution continuous animation and cleanup. No synthetic frame interpolation is used.

Validation: TypeScript and production build checks; complete FFmpeg decode; dimensions/duration/audio stream check; asset, caption, shot and rendered-drawing coverage; source-sheet and rendered contact-sheet inspection against actual card portraits. The existing 298 gameplay tests passed for the first prototype; this correction changes art, media selection, renderer output routing and page styling. Managed browser-control capability was unavailable, so browser/phone interaction, fullscreen behavior and audible playback remain unverified. This limitation is recorded in `docs/art/gokart-card-style/render-report.json`.
